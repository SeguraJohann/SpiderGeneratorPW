# SpiderGeneratorPW

Generador de spiders para Playwright en Python.

## Descripción

Proyecto en Python para generar spiders (scrapers) utilizando Playwright como motor de automatización de navegador.

## Requisitos

- Python 3.8+
- Playwright

## Instalación

```bash
pip install -r requirements.txt
playwright install
```
